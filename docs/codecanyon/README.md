## Install in 3 steps

1. In WordPress admin, go to **Plugins → Add New → Upload Plugin**.
2. Select `infinitycod.zip`, click **Install Now**, then **Activate**.
3. Open **InfinityCod** in the admin menu and follow the setup wizard (Wilayas → Transporteurs → Formulaire).

WooCommerce must be installed and active. Full guide: `documentation/documentation.md`.
